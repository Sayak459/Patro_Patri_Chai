# Patro Patri Chai

An Angular 16 website for the Patro Patri Chai experiences.

## Routes

- `/` - Experience selector
- `/dating` - Dating experience
- `/wedding` - Bibaho wedding experience

## Run locally

```bash
npm install
npm start
```

Open the local URL printed by Angular CLI, usually `http://localhost:4200/`.

## Project structure

- `src/app/landing` - Experience selector
- `src/app/dating` - Dating page and section components
- `src/app/bibaho` - Wedding experience
- `src/app/shared` - Shared scrolling utilities and reveal directive
- `src/assets` - Site images and logo
